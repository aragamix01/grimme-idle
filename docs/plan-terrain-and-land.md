# แผน: ภูมิประเทศสุ่ม ที่ดินที่คนจับจองเอง ถนนจากรอยเท้า กำแพงตามขอบเมือง

เป้าหมาย: เลิกใช้ผังตายตัวใน `town.ts` (LOTS, PLOTS, FIELDS, PASTURE, FOREST, POND, WALL, GATES, SHACK_SPOTS) ให้ทุกเกมเริ่มจากป่าและภูมิประเทศที่สุ่มจาก seed แล้วให้คนในเมืองจับจอง ถาง สร้าง และล้อมรั้วเอง บนแผนที่ที่ใหญ่ขึ้น

ทำเป็น 4 ขั้น แต่ละขั้นเล่นได้และผ่าน typecheck / test:sim / balance (สองเมือง) / e2e ก่อนไปขั้นถัดไป

---

## สภาพตอนนี้ (จากการสำรวจ)

- `town.ts` ผูกทุกอย่างไว้กับพิกัดคงที่ ใช้ใน 14 ไฟล์ประมาณ 100 จุด
- `PLACES` ใน `places.ts` เป็นค่าคงที่ระดับ module คิดจาก `BUILDINGS` ตอนโหลด ใช้ 40 จุดใน 10 ไฟล์ (sim และ UI) เปลี่ยนตามโลกไม่ได้
- ฉากรอบเมืองใช้ `createRng(1847)` และ WorldScene ใช้ `seed = 7` ป่ากับหญ้าจึงเหมือนกันทุกเกม
- **แผนที่โลก (`WorldMapScene`, `lands.ts` partition) ใช้ `MAP_W`/`MAP_H` ตัวเดียวกับแผนที่เมือง** ขยายเมืองเมื่อไหร่โลกจะขยายตาม
- `nav.ts` `insideWalls` / `onWall` เป็นสี่เหลี่ยม `WALL` ตายตัว ใช้แม้ยังไม่มีกำแพง
- `createWorld` มี `width: 40, height: 25` ที่ไม่มีใครอ่าน; ดันเจี้ยนแรกสุ่มที่ `x 30–37`
- canvas คงที่ `40*TILE × 25*TILE` (`main.ts`) กล้องซูม 1 = เห็นทั้งแผนที่ ลากได้เฉพาะตอนซูมเข้า
- WorldScene วาดพื้นทีละช่องเป็น image (1,000 ชิ้น) และ props ทั้งหมดเป็น image ที่เรียง depth ตาม y
- มีอยู่แล้วที่ต่อยอดได้: happening `clearing` (ถางป่าแบบตัวเลข `world.game`), สินค้า `timber`, `world.game` (สัตว์ป่า), `ruins`, `shacks`, `buildRev`

## ขั้นที่ 1: ภูมิประเทศสุ่มและแผนที่ใหญ่ขึ้น

ผังเมืองยังเป็นแม่แบบเดิม แต่ไปวางบนจุดที่ดีที่สุดของภูมิประเทศที่สุ่มใหม่ทุกเกม

### 1a. แยกขนาดแผนที่ (refactor ล้วน ไม่เปลี่ยนพฤติกรรม, commit แยก)
- `WORLD_W/WORLD_H = 40/25` สำหรับแผนที่โลก (`WorldMapScene.ts`, `lands.ts`)
- `TOWN_W/TOWN_H` สำหรับแผนที่เมือง (เริ่มที่ 40/25 ก่อน แล้วค่อยขยายใน 1d)
- ลบ `width/height` ที่ไม่มีคนอ่านใน `createWorld`

### 1b. `PLACES` กลายเป็นฟังก์ชันของโลก
- `places(world)` แคชตาม `buildRev` แทนค่าคงที่ module; แก้ 40 จุดที่เรียก
- ใน 1c จุดทั้งหมดจะเลื่อนตาม `world.site`

### 1c. `src/sim/terrain.ts` (ใหม่)
- `Terrain = 'meadow' | 'forest' | 'thicket' | 'water' | 'marsh' | 'rock' | 'hill'`
- `terrainOf(world)`: สร้างจาก `world.seed` แบบ deterministic (value noise สองชั้นเขียนเอง ไม่ต้องเพิ่ม dependency) แคชตาม seed ไม่เก็บลง save
  - แม่น้ำ: random walk คดเคี้ยวจากขอบหนึ่งไปอีกขอบ + หนองตามริมน้ำ
  - ป่า: noise ความหนาแน่น → `forest` / `thicket` (ทึบ เดินช้ามาก)
  - เนินและหิน: ชั้น noise ที่สอง มีจุดแร่ (`ore`) และดินเหนียวติดไว้
- **ภูมิประเทศตามแคว้นของเราใน `lands.ts`**: ดินแดนบ้านเป็น `woods` → ป่าหนาขึ้น, `shore` → ชายฝั่งด้านหนึ่ง, `hills` → เนินมาก, `plain` → ทุ่งกว้าง
- `pickSite(terrain)`: ให้คะแนนจุดกลางที่เป็นไปได้: ทุ่งราบพอวางแม่แบบ, มีน้ำในระยะ 6, มีป่าในระยะ 10, ห่างขอบ ≥ ระยะที่เมืองจะโตได้, ไม่ทับหนอง เก็บใน `world.site`
- ใต้ footprint ของแม่แบบ (ถนน แปลงบ้าน นา ทุ่งหญ้า) ถูกถางให้เป็น meadow เพื่อให้ขั้นนี้ไม่ต้องมีงานถาง
- `townLayout()` วาดจาก terrain แทน `createRng(1847)`: ต้นไม้ตาม `forest`, พุ่มตาม `thicket`, หินตาม `rock`, น้ำตาม `water`
- `COST` เพิ่ม: `thicket` 6, `marsh` 4, `hill` 3, `rock`/`water` 0

### 1d. ขยายแผนที่เป็น 96×64 (ข้อเสนอ; 80×50 ถ้า perf บนมือถือไม่ไหว)
- **nav**: 6,144 ช่อง Uint16 พอ (ต้นทุนสูงสุดยังต่ำกว่า 65,535) flow field ละ 12 KB; จำกัดแคชด้วย LRU ~64 เป้าหมาย
- **render**: พื้นอบลง `RenderTexture` ครั้งเดียวต่อ `buildRev` แทน image ทีละช่อง; ต้นไม้ในป่าไกลจากเมือง (> 6 ช่องจากสิ่งก่อสร้าง) อบลงชั้นเดียวกัน (คนไม่เดินผ่านจึงไม่ต้องเรียง depth) ส่วนต้นไม้ใกล้เมืองยังเป็น sprite
- **กล้อง**: canvas คงที่ 8:5 เหมือนเดิม (กฎมือถือ) ซูม 1 = มอง 40×25 ช่องรอบเมือง ซูมออกได้จนเห็นทั้งแผนที่ (~0.42) ลากได้ทุกระดับซูม เปิดเกมกลางเมือง ปุ่มซูมใน `#map-tools` วนระดับ
- ฝน น้ำท่วม แสงกลางคืน ใช้ขนาด `TOWN_W*TILE`
- ดันเจี้ยนเกิดใน `forest`/`thicket` ที่ห่างเมือง ≥ 15 ช่อง แทน `x 30–37`
- ทางเข้าเมืองคือถนนจากขอบแผนที่ด้านที่แคว้นเพื่อนบ้าน/คาราวานอยู่ (`PLACES.gate` เป็นจุดขอบแผนที่)

### test (`tools/simtest/tests.ts`)
- terrain deterministic ต่อ seed และต่างกันระหว่าง seed
- site มีน้ำในระยะ ทุก `places(world)` เดินถึงได้จากทางเข้า
- ดันเจี้ยนอยู่ในป่าและเดินถึงได้

### ความเสี่ยง
- ระยะเดินยาวขึ้นถ้าป่าอยู่ไกล: นายพรานและคนเลี้ยงสัตว์ใช้เวลาเดินมากขึ้น ต้องรัน balance สองเมือง
- e2e ที่แตะตำแหน่งบนแผนที่ต้องอ่านตำแหน่งจาก world แทนพิกัดคงที่

## ขั้นที่ 2: แปลงที่ดิน การถาง และคนเลือกที่เอง

เลิกแม่แบบ: ทุกอย่างบนแผนที่คือแปลงที่มีคนจับจอง

### โครงข้อมูล
```ts
interface Parcel {
  id: number;
  kind: 'home' | 'field' | 'pasture' | 'civic' | 'work' | 'commons' | 'grave';
  x: number; y: number; w: number; h: number;
  owner?: number | 'crown' | 'church';   // npc id ถ้าเป็นของคน
  key?: string;                          // civic / work: 'church', 'granary' ...
  since: number;
}
// world.parcels: Parcel[]; world.cleared: string  (bitset ช่องที่ถางแล้ว เข้ารหัส base64)
```
- `Home.lot` → `Home.parcel`; `LOTS`, `PLOTS`, `BUILDINGS` (พิกัด), `FIELDS`, `PASTURE`, `FOREST`, `POND`, `SHACK_SPOTS` ถูกลบ
- `townLayout()` อ่านจาก terrain + cleared + parcels คีย์แคชรวม parcels
- `places(world)` อ่านประตูอาคารจาก parcel ของ civic นั้น

### การถาง (`src/sim/clearing.ts` ใหม่)
- แปลงที่จับจองบนป่าต้องถางก่อนใช้: `forest` 3 แรงงาน-วันต่อช่อง, `thicket` 6, `marsh` ระบายน้ำ 8; ได้ `timber` เข้าตลาด
- คนทำ: ช่างก่อสร้างและเจ้าของแปลงเอง (ชาวนาถางนาตัวเองในวันว่าง) — เช็กกฎ "ชาวนามาก่อน" ห้ามดึงคนจากนาที่ขาดมือ
- `world.game` สูงสุดคิดจากจำนวนช่องป่าในระยะล่าสัตว์ แทน `GAME_CAP` คงที่: ถางมากสัตว์ป่าน้อยลงเอง
- happening `clearing` เปลี่ยนเป็นการถางป่าผืนใหญ่จริง (เลือกผืนป่าที่ใกล้นาที่สุด) แทนการลด `world.game` ตรง ๆ

### ใครเลือกที่ (`src/sim/landplan.ts` ใหม่)
- **ครัวเรือนเลือกที่สร้างบ้าน** (ตอน `housing.ts` เริ่มสร้างบ้าน): ให้คะแนนจุด 2×2 ที่ว่าง: ใกล้บ้านญาติ (`ties.ts`), ใกล้ที่ทำงาน, ติดถนนหรือทางเดิน, คนรวยใกล้ปราสาท/ศาลากลาง, คนจนยอมไกล, ไม่ติดชุมชนแออัด, ถางง่าย ย่านต่าง ๆ จึงเกิดเอง
- **ชาวนาจับจองนา**: แต่ละครอบครัวชาวนามีนา ~6 ช่อง ต่อจากนาเดิม ใกล้น้ำได้คะแนนดินมากกว่า; `harvest()` คูณด้วยความอุดมเฉลี่ยของนา และชาวนาที่ไม่มีนาผลิตน้อยลง (แรงจูงใจให้ถาง)
- **คนเลี้ยงสัตว์จับจองทุ่ง** ติดโรงนา
- **ผู้ปกครองวางอาคารสาธารณะ** (ตอน `growth.ts` เริ่มก่อตั้ง และ `works.ts` เริ่มงานหลวง): ผู้ตัดสินคือคนเดียวกับที่ตัดสิน happenings (ผู้ใหญ่บ้านในค่าย กษัตริย์ สภาในสาธารณรัฐ) ให้คะแนนตามรูปแบบผัง (ขั้น 4) ตอนนี้ใช้ "ใกล้ใจกลาง ติดถนน"
- **ทุ่งสาธารณะ (`commons`)**: ทุ่งหญ้าที่ไม่มีเจ้าของรอบหมู่บ้าน ใช้เลี้ยงสัตว์ได้ทุกคน (ใช้ใน happening ล้อมรั้วขั้น 4)

### ระบบเดิมที่ต้องปรับ
- `housing.ts`: สร้างบ้านบน parcel ใหม่แทน `LOTS.findIndex`; "นอกกำแพง" อ่านจากหน้ากากกำแพง (ขั้น 3) — ขั้นนี้ใช้ระยะจากใจกลางแทนชั่วคราว
- `slums.ts`: เพิงเกิดบนช่องว่างไม่มีเจ้าของที่ใกล้ถนนที่สุดชายขอบเมือง แทน `SHACK_SPOTS`; ไฟลามตามช่องข้างเคียงจริง
- `disasters.ts`: น้ำท่วมตามแนวแม่น้ำ (ช่องต่ำที่ห่างน้ำ ≤ 3) แทนแถว `FIELDS`; โรคพืชเฉพาะแปลงนา
- `quests.ts`, `world.ts` (ชาวนา/คนเลี้ยงสัตว์/นายพรานเดินไปทำงาน): สุ่มช่องในแปลงของตัวเอง / ป่าใกล้สุด แทน rect คงที่
- `createWorld('town')` (เมืองเต็มของ test): วางแปลงทั้งหมดทันทีด้วย planner เดียวกัน เพื่อให้ test ของ sim ยังได้เมือง 120 คน
- UI: `kingdom.ts` ส่วนบ้าน "แปลงว่าง" → นับช่องที่ยังจับจองได้; เมนูแผนที่เพิ่ม "ผังที่ดิน" (overlay สีตามชนิดแปลง) + e2e

### test
- ครัวเรือนที่มีญาติสร้างบ้านใกล้ญาติ; คนรวยใกล้ใจกลางกว่าคนจน
- ถางป่าแล้วได้ timber และ `game` สูงสุดลดลง
- ชาวนาไม่มีนาจับจองนาติดนาเดิม; ค่ายไม่อดตาย (balance ค่ายปี 1–3)

## ขั้นที่ 3: ถนนจากรอยเท้า รั้ว ระเนียด กำแพง

### ทางเดินที่คนเหยียบจนเป็นถนน
- `walk()` ใน `nav.ts` บวก `wear[i]` (Uint16Array ไม่เข้า save ทุก tick; เก็บสรุปเดือนละครั้ง)
- เดือนละครั้ง: ช่องที่ wear เกินเกณฑ์กลายเป็น `trail` แล้ว `buildRev++` ครั้งเดียว (ไม่ทำแผนที่ใหม่ทุกวัน); ทางที่ไม่มีคนเดินนานกลับเป็นหญ้า
- สเกลต้นทุนใหม่ (คูณสอง ให้มีช่องว่างระหว่างระดับ): หญ้า 4, `trail` 3, `road` 2, `paved` 1
- งานหลวงใหม่ใน `works.ts`: **ปูถนน** ผู้ปกครองเลือกเส้นที่ wear สูงสุดเชื่อมอาคารสาธารณะ จ่ายต่อช่อง ใช้แรงช่างก่อสร้าง
- `Ground` เพิ่ม `trail` / `paved` + sprite ใหม่ใน `tools/sprites`

### รั้ว
- ชาวนาล้อมรั้วนาเมื่อทุ่งเลี้ยงสัตว์อยู่ติดกัน (ถ้าไม่ล้อม: mod `harvest` ลดเล็กน้อยจากสัตว์เหยียบ)
- คนเลี้ยงสัตว์ล้อมรั้วทุ่งเมื่อมีโรงนา
- รั้วใช้ timber และไม่บังการเดินที่ช่องประตูรั้ว

### ระเนียดและกำแพง
- civic ใหม่ `palisade` (ระเนียดไม้) ที่ขั้นหมู่บ้าน ใช้ timber; `walls` (หิน) ที่ขั้นเมือง; `outerwalls` ที่ขั้นนคร
- แนวกำแพง = ช่องของแปลง home/civic ขยายออก 2 ช่อง แล้วหา orthogonal convex hull ได้วงล้อม; ประตูเกิดตรงที่ trail/road ตัดแนว; เก็บแนวไว้ตอนเริ่มสร้าง (ไม่ขยับตามทีหลัง)
- `nav.ts` `insideWalls`/`onWall` อ่านหน้ากากจาก flood fill ภายในแนวกำแพงที่เก็บไว้ แทน rect `WALL`
- บ้านนอกแนวคือย่านนอกกำแพง; เพิงชุมชนแออัดเกาะอยู่นอกแนว
- ค่าก่อสร้างคิดตามความยาวแนว: เมืองที่แผ่กว้างจ่ายแพงกว่า (เหตุผลให้สร้างกำแพงเร็วหรือกระชับเมือง)

### test
- ทางที่คนเดินบ่อยกลายเป็น trail ภายในหนึ่งเดือน; ไม่มีคนเดินแล้วหายไป
- แนวกำแพงล้อมทุกอาคารสาธารณะ; ประตูอยู่บนถนน; ทุกที่ในเมืองยังเดินถึงทางเข้า

## ขั้นที่ 4: การเมือง เหตุการณ์ ภัย และพลังเทพ

### รูปแบบผังตามผู้ปกครอง
- `planStyle(world)`: `'grid' | 'radial' | 'organic'`
  - ราชาธิปไตย → radial รอบปราสาท; สาธารณรัฐ → grid รอบลานตลาด; เทวาธิปไตย → radial รอบโบสถ์; ค่าย/ผู้ใหญ่บ้าน → organic
  - นิสัยผู้ปกครองดันเพิ่ม (ระเบียบ → grid, ทะเยอทะยาน → ถนนกว้าง)
- ใช้ใน landplan (ที่วางอาคาร) และงานปูถนน (grid ตัดตรงตามแกน) → เปลี่ยนผู้ปกครองแล้วเมืองส่วนที่โตต่อจากนั้นหน้าตาต่าง

### happenings ใหม่ (`happenings.ts` + ตัวนับใน `tools/balance/town.ts`)
- `enclosure` ขุนนางขอล้อมทุ่งสาธารณะเป็นทุ่งของตัวเอง: ขุนนางรวย, คนเลี้ยงสัตว์และชาวนาจนเสีย
- `sacredgrove` ถางป่าศักดิ์สิทธิ์ทำนา: ได้นา vs ศาสนจักรไม่พอใจ (`pietyPull` เทอมใหม่ผ่าน mod)
- `roadthrough` ตัดถนนผ่านบ้าน: ไล่ที่ (ครัวเรือนเสียบ้าน ได้ค่าชดเชยจากคลัง) vs ถนนอ้อม (แพงกว่า)
- `landclaim` สองครัวเรือนอ้างแปลงเดียวกัน → คดีใน `justice.ts`

### ภัย
- ไฟป่าลามตามช่องป่าในฤดูแล้ง ถึงบ้านไม้ได้ (ต่อจากไฟใน `slums.ts`)
- แม่น้ำล้นตลิ่งตามแนวน้ำจริง; หน้าแล้งหนองแห้ง

### ป่าและอันตราย
- ความอันตรายของป่า = จำนวนช่องป่าทึบใกล้เมือง: มอนสเตอร์ (`troubles.ts`) โผล่จากขอบป่า; ดันเจี้ยนใหม่เกิดในป่าลึก; ถางแล้วปลอดภัยขึ้นแต่สัตว์ป่าน้อยลง

### ปาฏิหาริย์ (`divine.ts`)
- ปลูกป่า (ฟื้นช่องที่ถางแล้วเป็นป่า: สัตว์ป่ากลับ นายพรานพอใจ ชาวนาเสียที่)
- ตาน้ำ (เปิดน้ำบนช่องที่เลือก: นารอบ ๆ อุดมขึ้น)
- ฟ้าผ่าถางป่า (ถางทันทีแต่เสี่ยงไฟลาม)

## สิ่งที่ต้องแก้ใน CLAUDE.md เมื่อแต่ละขั้นเสร็จ
- ตารางระบบหลัก: เพิ่ม `terrain.ts`, `clearing.ts`, `landplan.ts`; แก้แถวบ้านเรือน (เลิก `LOTS`)
- หลักของเมือง: `places(world)` แทน `PLACES`, ขนาดแผนที่เมือง/โลกแยกกัน, แปลงที่ดิน, สเกลต้นทุนเดินใหม่, wear อัปเดตเดือนละครั้งเท่านั้น
- หน้าจอ: กล้องซูมออกได้และลากได้ทุกระดับ, overlay ผังที่ดิน
